# Study Helper — помічник для конспекту (Gemini API, C#)

PoC для лабораторної роботи 2 з курсу «Хмарні обчислення»: консольний застосунок на C#, який бере текст
конспекту і через **Google Gemini API** повертає стислий переказ та запитання для самоперевірки з відповідями.

## Де це можна використати

- Підготовка до заліків: швидкий переказ конспекту й автоматичні питання для повторення.
- Стислий підсумок довгих документів, статей, протоколів.
- Основа для чат-бота або модуля тестування в навчальних платформах.

## Які API використовуються

| API | Метод | Для чого |
|---|---|---|
| Gemini API (Google AI) | `POST /v1beta/models/{model}:generateContent` | Аналіз конспекту і генерація переказу та запитань |
| Gemini API (Google AI) | `GET /v1beta/models` | Перевірка доступних моделей (під час розробки) |

Використано **structured output**: у запиті `generationConfig` задано `responseMimeType: application/json` і
`responseSchema`, тому модель повертає гарантовано розбірний JSON, а не вільний текст.

## Як взаємодіють сервіси

```
Користувач ──(файл конспекту)──> StudyHelper (C#, консоль)
                                       │  HTTPS POST generateContent
                                       │  заголовок x-goog-api-key, prompt + responseSchema
                                       ▼
                              Gemini API (Google Cloud)
                                       │  JSON { summary, questions[{question, answer}] }
                                       ▼
                              StudyHelper розбирає JSON ──> друкує переказ і запитання
```

Ключ береться зі змінної середовища `GEMINI_API_KEY` і ніколи не потрапляє в код чи репозиторій.

## Структура

- `StudyHelper/Program.cs` — вхід: перевірка аргументів, читання файлу, виклик клієнта, вивід.
- `StudyHelper/GeminiClient.cs` — REST-клієнт `generateContent`, схема відповіді, обробка помилок (429, невірний ключ, порожня відповідь).
- `StudyHelper/Models.cs` — типи відповіді (`StudyResult`, `QuizItem`).
- `samples/` — приклади конспектів для демо.

## Запуск

Потрібно: .NET SDK 9 і API-ключ з [Google AI Studio](https://aistudio.google.com/).

```powershell
# 1. Ключ (один раз; перезапусти термінал після цього)
setx GEMINI_API_KEY "<твій_ключ>"

# 2. Запуск: файл конспекту і (необов'язково) кількість запитань
dotnet run --project StudyHelper -- samples\conspect1_parallel.txt 5
```

Модель за замовчуванням — `gemini-2.5-flash`; можна змінити змінною `GEMINI_MODEL`.

## Обробка помилок

| Ситуація | Поведінка |
|---|---|
| Немає `GEMINI_API_KEY` | Повідомлення, код виходу 1 |
| Файл не знайдено або порожній | Повідомлення, код виходу 1 |
| Хибний ключ (400/401/403) | «Ключ API не прийнято», код виходу 2 |
| Ліміт запитів (429) | «Перевищено ліміт, зачекай хвилину», код виходу 2 |
| Порожня відповідь / блокування фільтром | Повідомлення, код виходу 2 |

## Обмеження

- Free tier Gemini має ліміти на частоту запитів і довжину контексту.
- Модель може помилятися; для цього в промпті вимагається спиратися лише на текст конспекту, але перевірка відповідей залишається за людиною.
- Текст конспекту надсилається на сервери Google; не використовуй конфіденційні матеріали.
