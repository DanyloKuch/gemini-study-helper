# Шпаргалка: live-демо на парі (лаба 2)

## Вдома, заздалегідь

1. Відкрий **новий** термінал (старі не бачать нового ключа) і перевір, що ключ на місці:
   ```powershell
   if ($env:GEMINI_API_KEY) { "ключ є" } else { "ключа немає" }
   ```
2. Один раз прожени демо повністю, щоб переконатися, що Gemini відповідає:
   ```powershell
   cd "D:\унік\Хмарні\gemini-study-helper"
   dotnet build StudyHelper
   dotnet run --no-build --project StudyHelper -- samples\conspect2_cloud.txt 4
   ```
3. Відкрий `presentation\Lab2_presentation.pptx` і на слайді 6 клацни по відео: воно має програватися.

## На парі, за 5 хвилин до виступу

1. Ноутбук до інтернету (бажано не через університетський Wi-Fi з обмеженнями, а роздача з телефону).
2. Відкрий **два вікна**: презентацію і термінал у теці `gemini-study-helper`.
3. У терміналі збільш шрифт (Ctrl + коліщатко), щоб із задніх парт було видно.
4. Набери команду запуску заздалегідь, але **не тисни Enter**:
   ```powershell
   dotnet run --no-build --project StudyHelper -- samples\conspect2_cloud.txt 4
   ```

## Під час виступу (слайд 6)

1. Скажи: «Зараз покажу вживу. Ось конспект про хмарні обчислення» і покажи його:
   `Get-Content samples\conspect2_cloud.txt`
2. Тисни Enter на команді запуску.
3. Поки чекаєш 5–10 секунд: «Програма зараз відправила конспект у Gemini API разом зі схемою відповіді».
4. Коли з'явиться результат: «Ось переказ, а ось чотири запитання з відповідями. Усе взято лише з тексту конспекту».

## Якщо щось пішло не так

| Що бачиш | Що робити |
|---|---|
| `Перевищено ліміт запитів (429)` | Сказати «спрацював ліміт безкоштовного тарифу, ось запис» і клацнути по відео на слайді 6 |
| `Закінчились кредити проєкту (402)` | Те саме: показати відео |
| `Ключ API не прийнято` | Термінал старий: відкрий новий або покажи відео |
| Немає інтернету / довго висить | Ctrl+C і відео |

Кожна з цих помилок теж непогано виглядає на демо: видно, що програма їх обробляє зрозумілим повідомленням, а не падає.

## Якщо спитають

- **Чому C# без SDK?** Видно, які саме HTTP-запити йдуть до API, і немає зайвих залежностей.
- **Як гарантується формат відповіді?** Через `responseSchema`: Gemini зобов'язаний повернути JSON з полями `summary` і `questions`.
- **Де ключ?** У змінній середовища `GEMINI_API_KEY`, в коді й на GitHub його немає.
- **Скільки коштує?** Безкоштовний тариф Gemini API, з обмеженням на кількість запитів.
